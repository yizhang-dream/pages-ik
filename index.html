24 个术语

FK / 正向运动学

输入局部关节旋转，通过父子递推得到世界关节位置与朝向。

IK / 逆运动学

给末端目标等约束，求关节参数。常有多个合法解。

局部 / 世界坐标

局部坐标相对某关节或物体参考系；世界坐标相对共同场景参考系。先明确向量和矩阵所属坐标系。

静止偏移 rest_offset

子关节在父坐标系中的静止位移。其长度定义固定骨长，不是求解后的世界位置。

骨长 lᵢ / 总长 L

lᵢ 是一根直骨的长度，L=Σlᵢ。求解不能为了到目标而静默伸缩它。

弦长 d / 曲线弧长 S

d 是两个端点的直线距离；S 是沿曲线走过的长度。弯曲时通常 S>d。

单位向量 / 归一化

v/‖v‖ 仅对非零向量有定义。零方向需要确定性回退并说明。

点积 / 叉积

点积量化夹角投影；叉积给垂直方向和旋转方向。注意使用右手约定。

pole / 弯曲提示

本项目主要作为世界方向使用；对弦或骨轴投影得到有效垂直分量。不是自动给出完整关节姿态。

可达范围

r最大=Σlᵢ；r最小=max(0,2max(lᵢ)−Σlᵢ)。几何可达与迭代收敛是两回事。

球面投影

已知中心 q 与半径 l，将 p 变成 q+l·normalize(p−q)，用于固定骨长。

硬约束 / 软约束

骨长等硬约束需要满足并检查；形状吸引等偏好可被放松，须报告偏离。

扭转 twist

绕自身骨轴的自转。保持骨向，但改变关节参考轴朝向；位置无法唯一确定它。

最短弧旋转

在把一条非零方向转到另一方向的所有旋转中，选旋转角最小的一个，作为确定性恢复规则。

导数 C′ / 速度

参数改变时位置的局部变化率。曲线速率为 ‖C′‖，参数未必代表时间。

积分 / 累计弧长

把极小段长度累加，得到 s(u)=∫₀ᵘ‖C′(v)‖dv。用于决定按骨长走到哪个参数。

二分求根

已知单调函数且区间夹住目标时，反复比较中点并缩小区间。使用前要检查可行性。

Gauss–Legendre 求积

用特定节点与权重近似积分。当前广义 Helix 用四段、每段32点；须独立检查精度。

Helix / 螺距 p

螺旋绕轴推进，p 是每圈轴向推进量，N 是圈数。标准版半径与螺距恒定。

taper_radius / taper_pitch

分别为终点减起点的半径、螺距变化量，记 Δr、Δp，单位与骨长相同。

r̄ / p̄

起终参数的平均值。当前广义 Helix 先显式解 p̄，再由总弧长二分解 r̄。

标架 / 平行输运

标架给曲线切线和横向参考轴；平行输运以尽量小的旋转搬运标架。提供函数不等于最终求解器采用。

SUCCESS / MAX_ITERATIONS

前者表示当前状态条件成功；后者表示数值过程耗尽轮数仍未达到阈值，不能当作几何不可达。

DEGENERATE / UNREACHABLE

不同求解器映射可能有差异，应结合 message 与回退信息读；本项目内不可达常用退化回退。
